# Telegram Бот-Органайзер и Напоминатель встреч с ИИ Gemini (Python 3.14)

Умный асинхронный Telegram-бот для создания **напоминаний о встречах, делах и задачах** с пониманием естественного языка на базе **Google Gemini API** (`google-genai`), сохранением в **SQLite** и фреймворком **aiogram 3**.

---

## 🚀 Возможности
- ⏰ **Умные напоминания:** Понимание фразы в свободной форме (например: *«Напомни завтра в 15:00 про встречу с клиентом»*, *«Через 30 минут выключить духовку»*).
- 🧠 **ИИ распознавание (Google Gemini):** Автоматическое выявление названия дела, точной даты и времени.
- 🔔 **Уведомления в реальном времени:** Фоновый планировщик (`scheduler.py`) проверяет базу каждые 10 секунд и присылает уведомление прямо в Telegram.
- 🔘 **Интерактивные кнопки:**
  - ✅ **Выполнено:** Отметить задачу завершенной.
  - 🗑️ **Удалить:** Удалить из базы.
  - ⏰ **Отложить:** На +15 минут, +1 час или на завтра прямо из уведомления.
- 📋 **Список дел:** Удобная команда `/list` или кнопка **«📋 Мои напоминания»**.
- 💬 **Свободный ИИ чат:** Если сообщение не является напоминанием, бот отвечает как умный собеседник.
- 💾 **Надежная база данных:** Сохранение всех напоминаний в локальный файл SQLite (`reminders.db`).

## ☁️ Деплой на Railway

1. Создайте новый проект на [Railway.app](https://railway.app/).
2. Загрузите код из GitHub или через CLI Railway.
3. Во вкладке **Variables** добавьте ключи:
   - `BOT_TOKEN`
   - `GEMINI_API_KEY`
   - `GEMINI_MODEL`
   - `PYTHONUNBUFFERED=1`
4. Railway автоматически запустит бота по команде `python main.py`.

## 🕹 Команды в Telegram

- `/start` — Приветственное меню и главный интерфейс.
- `/list` — Посмотреть список всех активных напоминаний.
- `/add` — Подсказка по добавлению нового напоминания.
- `/clear` — Сбросить контекст свободного диалога с ИИ.
- `/help` — Справка по работе с ботом.
