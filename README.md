# Telegram Bot с ИИ чатом Google Gemini (Python 3.14.7)

Современный асинхронный Telegram-бот с поддержкой диалогов на базе **Google Gemini API** (`google-genai`) и фреймворка **aiogram 3**.

---

## 🚀 Возможности
- 🤖 **ИИ Чат:** Общение с моделью Google Gemini (по умолчанию `gemini-2.5-flash`).
- 🧠 **Память диалога:** Индивидуальный контекст беседы для каждого пользователя.
- 🧹 **Сброс памяти:** Команда `/clear` для начала новой темы с чистого листа.
- 🔒 **Безопасность:** Хранение ключей в файле `.env`.
- ⚡ **Асинхронность:** Быстрый отклик на базе `aiogram 3` и `asyncio`.
- 📝 **Длинные сообщения:** Автоматическая разбивка ответов длиннее 4000 символов.
- ⌨️ **Индикатор печати:** Отображение "печает..." в Telegram во время генерации ответа.

---

## 📋 Требования
- **Python:** `3.14.7` (или Python `3.10+`)
- Пакеты: `aiogram>=3.17.0`, `google-genai>=1.0.0`, `python-dotenv>=1.0.1`

---

## 🔑 Как получить ключи доступа

1. **Telegram Bot Token (`BOT_TOKEN`):**
   - Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
   - Отправьте команду `/newbot` и следуйте инструкциям.
   - Скопируйте полученный API токен (вид: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

2. **Google Gemini API Key (`GEMINI_API_KEY`):**
   - Перейдите на [Google AI Studio](https://aistudio.google.com/).
   - Войдите в аккаунт Google и нажмите **Get API key** -> **Create API key**.
   - Скопируйте созданный ключ API.

## 🛠 Настройка и Запуск

### 1. Заполнение конфигурации `.env`
Откройте файл `.env` в корневой папке бота и вставьте ваши ключи:

```env
BOT_TOKEN=ваш_telegram_bot_token
GEMINI_API_KEY=ваш_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash
```

### 2. Установка зависимостей
Если вы запускаете проект впервые на новом ПК/окружении:

```bash
python -m pip install -r requirements.txt
```

### 3. Запуск бота

```bash
python main.py
```

---

## 🕹 Команды в Telegram

- `/start` — Приветствие и справка по работе с ботом.
- `/help` — Подробная информация о командах.
- `/clear` — Очистить историю контекста диалога и начать сначала.
